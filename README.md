# Immersea OTA Updates

Distribuzione pubblica dei pacchetti installabili Immersea, senza codice sorgente.

I pacchetti sono allegati alle Releases, con manifest, versione, compatibilità,
firma Android e checksum SHA-256. Il catalogo contiene un indice per app e canale.

Il download è pubblico e non richiede credenziali. La pubblicazione è riservata
ai manutentori autorizzati. Prima di installare occorre verificare compatibilità,
versione crescente, firma e checksum. L'installazione resta esplicita.

GitHub genera automaticamente gli archivi denominati “Source code (zip/tar.gz)”
per ogni release. Qui contengono solo questo documento e i manifest JSON, non
sorgenti applicativi o script. Il codice e l'automazione restano nel monorepo privato.
